== Modules

The modular design of gPC is such
that one can start with the basic
instruction set, and then add
additional modules as needed. The
<<io_control, I/O and Additional
Control>> module is the one you're
most likely to add first, but other
modules are not inter-dependent, and
as such can be added in any order.
